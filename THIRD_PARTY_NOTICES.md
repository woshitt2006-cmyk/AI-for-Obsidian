# Sources and third-party material

The Python runtime code uses the standard library only. The Windows window uses system PowerShell and Windows Forms. Neither a Python runtime nor third-party dependencies are redistributed in this repository.

The demo vault contains AI-generated educational notes and original explanatory calculations, with source links in the notes/graph. It does not redistribute the papers themselves. Linked publications retain their own copyrights and licenses; this repository's MIT license does not grant rights to those publications.

Principal linked scientific references include:

- Kristensen, Niordson, Martínez-Pañeda, *An assessment of phase field fracture: crack initiation and growth*: https://arxiv.org/html/2103.05443v2
- de Borst, Verhoosel, *Gradient damage vs phase-field approaches for fracture: similarities and differences*: https://eprints.whiterose.ac.uk/id/eprint/100669/
- DefElement, *How to define a finite element*: https://defelement.org/finite-elements.html
- MFEM, *Integration*: https://mfem.org/integration/
- JSON Canvas specification: https://jsoncanvas.org/spec/1.0/

The demo is provisional research-learning material, not an endorsed summary of any author. Review source scope and mathematical assumptions before scientific reuse.
