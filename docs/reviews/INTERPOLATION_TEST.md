## 需要限定或修正的表述

1. “有限元不能直接表示连续函数”过强：所选有限元空间可精确表示其中的连续函数，但不能精确表示任意连续函数。
2. 形函数在节点取 1/0 是这里讨论的节点型 Lagrange 基的性质，不是所有有限元的普遍点值性质；更一般的自由度可以是导数或矩。
3. 节点系数在求解前仍未知；对空间坐标求导时是常数，并不表示随时间或迭代始终不变。
4. “有限元离散误差包括数值求解误差”混合了误差来源。空间离散误差与有限容差的迭代求解误差应区分；插值误差也不等于最终有限元解的全部误差。
